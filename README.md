# Planificación Jaime

Panel de planificación fiscal y de ahorro para la entrada de una casa.

- **Reparto de dinero:** cuánto va a cada cuenta (Sabadell, ING y ahorro Sabadell).
- **Planificación mensual:** gastos de vida, ingresos extras y datos fiscales, mes a mes.
- **Planificación casa:** plazo para llegar a la entrada, hipotecas y escenarios.
- **Resumen:** filtro por mes y total.

`index.html` es una página única sin dependencias de compilación. Los datos se guardan con el botón «Guardar y actualizar» en el artefacto de Claude donde está publicada.
